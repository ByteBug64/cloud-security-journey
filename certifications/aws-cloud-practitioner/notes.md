## Core Competencies

### A. IAM & Security
- Managed IAM Users, Groups, and Roles
- Enforced MFA on root and IAM users
- Applied Principle of Least Privilege using JSON policies
- Implemented password rotation and complexity policies

### B. Compute Services
- EC2 instance families (General Purpose, Compute Optimized, Memory Optimized)
- EC2 User Data for instance bootstrapping
- Security Groups (SSH Port 22, HTTP Port 80)
- Elastic Load Balancing & Auto Scaling Groups
- AWS Lambda (serverless), ECS & Fargate (containers)

### C. Storage & Databases
- S3 storage classes: Standard, Intelligent-Tiering, Standard-IA, Glacier
- S3 versioning for data protection
- EBS persistent block storage + snapshots
- RDS (MySQL, PostgreSQL) and DynamoDB (NoSQL)

### D. Networking & Content Delivery
- VPC with Public and Private Subnets
- NAT Gateways for private subnet outbound access
- Route 53 DNS routing (Simple, Weighted, Failover)
- CloudFront CDN for global content delivery

### E. Security, Compliance & Governance
- Shared Responsibility Model
- AWS Shield Standard & Advanced (DDoS protection)
- AWS Artifact for compliance reports (ISO, PCI-DSS)
- AWS KMS for encryption at rest and in transit

### F. Operations & Billing
- CloudTrail for auditing (who did what and when)
- CloudWatch for monitoring and alarms
- AWS Budgets & Cost Explorer
