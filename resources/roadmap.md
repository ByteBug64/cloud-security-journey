# Cloud Security Engineer Roadmap (Blue Team)

## Stage 1 — Foundation ✅
- Networking basics (TCP/IP, DNS, HTTP/S, firewalls)
- Linux fundamentals
- Security concepts (CIA Triad, encryption, common attacks)
- **Cert:** CompTIA Security+

## Stage 2 — Cloud Basics ✅
- AWS core services (IAM, VPC, EC2, S3, CloudTrail, CloudWatch)
- Shared responsibility model
- Encryption at rest vs in transit
- **Cert:** AWS Cloud Practitioner (CLF-C02) ✅ Jan 2026

## Stage 3 — Blue Team Core 🔄
- SIEM & Log Analysis (Splunk / Microsoft Sentinel)
- MITRE ATT&CK framework
- Incident Response playbooks
- AWS native security tools (GuardDuty, Security Hub, Config, Macie)
- **Cert:** CompTIA CySA+

## Stage 4 — Specialization 🔜
- Infrastructure as Code security (Terraform + Checkov)
- Container & Kubernetes security
- Cloud forensics
- Zero Trust architecture

## Stage 5 — Expert
- Custom threat detection rules
- Full IR simulations with post-mortems
- Open source contributions
- **Certs:** AWS Security Specialty · CCSP · GIAC (GCLD, GCIA)
